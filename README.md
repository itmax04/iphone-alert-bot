# iPhone Alert Bot

> **TL;DR (EN):** Cloudflare Worker that watches Kleinanzeigen (Germany) for private-seller iPhone 13+ listings
> in 23 prioritized cities around Rostock, sweeps all of Mecklenburg-Vorpommern every 3 hours, and separately
> picks the best deals across all of Germany (price vs. market median, resale margin), sending them to a private
> Telegram bot. Plain JavaScript (ES modules), no build step, state in Cloudflare D1. Docs are in Russian.

Бот для закупки iPhone на перепродажу. Три независимые функции:

| Функция | Что | Как часто | В Telegram |
|---|---|---|---|
| **Города** | новые iPhone 13+ в 23 городах из таблицы владельца | ⭐ 8 городов — каждые 10 мин, ▫️ 15 — каждые 30 мин | каждое объявление: ⭐ со звуком, ▫️ без звука |
| **Mecklenburg-Vorpommern** | вся земля, места вне списка городов | раз в 3 часа | одна тихая сводка |
| **Лучшие по Германии** | вся Германия, только выгодные | лента — каждые 5 мин | 🔥 сразу (≤ 6/день), 📋 «Топ-5» в 9, 13, 17, 21 ч |

Во всех сообщениях: модель, память, цена, аккумулятор, 💰 сравнение с медианой рынка, 📈 маржа (если заданы
цены продажи), 🚨 признаки обмана, кнопка **«✍️ Написать продавцу»** (готовый текст на немецком).

Фильтр поиска (в URL Kleinanzeigen): **только частные продавцы, только предложения о продаже**, категория 173
(Handy & Telefon), запрос «iphone»; модель 13+ определяется по заголовку (`modelOf`).

## Как это устроено

Каждый запуск обрабатывает **одну страницу** Kleinanzeigen (лимит бесплатного тарифа — 10 мс CPU на запуск).

```
cron "* * * * *"   10-минутный цикл (HIGH_CYCLE в src/index.js):
                    минуты 0–3, 5–8 → 8 городов ⭐ (каждый раз в 10 мин)
                    минуты 4 и 9    → лента «вся Германия» (лучшие предложения, раз в 5 мин)
                    + сводки 9/13/17/21 ч, отчёт 21:00, напоминание /sell по понедельникам 10:00,
                      ежечасная чистка старых записей (минута 30)
cron "*/2 * * * *" 15 городов ▫️ по кругу (каждый раз в 30 мин);
                    раз в 3 часа эти слоты на время обхода занимает вся MV (обычно 1–3 страницы)

runCity(city)   [index.js]  страница → id → сверка с seen → разбор только новых → фильтры → Telegram
runGermany()    [deals.js]  страница 1 (+2, если вся новая) → оценка выгоды → deals → 🔥 / сводка
runMvStep()     [mv.js]     одна страница MV → новые вне городов → в сводку по окончании обхода
POST /telegram  [commands.js] команды и кнопки
```

Время в cron — UTC; время для людей (сводки, отчёты, «день») — `Europe/Berlin`.

  telegram.js     обёртка Bot API

## Отбор, рынок, маржа, обман

- **Модель:** только iPhone 13 и новее (включая mini/Plus/Pro/Pro Max/16e/17/18/Air). Остальное — мимо.
- **Пометки (не отсеивают в городах):** 🔧 возможен дефект (defekt, Mängel, gesprungen, iCloud gesperrt…, но не «keine Mängel», «nicht gesperrt»), 🧩 аксессуар (слово-аксессуар в заголовке и нет объёма памяти), 🔁 обмен.
- **Фильтр цены `/price`:** общий min/max и лимит на модель (`settings.price`). Объявления без цены не отсеиваются.
- **Медиана рынка:** все увиденные iPhone 13+ (таблица `prices`, 30 дней, та же модель **и** память, ≥ 5 объявлений).
- **Маржа:** `/sell` — цены продажи владельца в Украине в ₴ (`settings.sell`, ключ `модель|память` или `модель|*`); курс EUR — НБУ (`bank.gov.ua`, кэш 12 ч). Маржа = продажа в € − цена покупки, «чисто перепродажа» (без доставки, растаможки, комиссий).
- **Звук в городах:** если для модели задана цена продажи — звук только у 🔥 (маржа ≥ `/margin`, по умолчанию 80 €, и нет 🚨); иначе — по приоритету города.
- **🚨 Обман:** цена < 50 % медианы; «neu/OVP» и < 70 % медианы; фразы nur Versand, PayPal Freunde, Vorkasse, Western Union, WhatsApp/Telegram, «bin/zurzeit im Ausland».

## Лучшие предложения по Германии

`src/deals.js`. Лента: `/s-handy-telekom/anbieter:privat/anzeige:angebote/sortierung:neuste/iphone/k0c173`
(без места), ~450 новых объявлений iPhone в час по Германии (88 тыс. всего, 17.10.2026). Если вся страница 1
новая — дочитывается страница 2.

**Выгодно**, если нет жёстких 🚨, цена ≥ 50 % медианы, есть память, не дефект/аксессуар, и
- на **25 %+** дешевле медианы (≥ 5 объявлений), **или**
- маржа ≥ `/margin` и скидка ≥ 10 %.

**🔥 Исключительно** — на **40 %+** дешевле (≥ 8 объявлений), без «nur Versand».

**Частота** (выбрана по данным MV: 50–65 % медианы — 0,8 % объявлений, 65–75 % — 2,3 %, ≥ 85 % — 88 %):
🔥 сразу со звуком, 8–23 ч, не больше 6 в день; остальное — сводка «Топ-5» в 9, 13, 17, 21 ч (дубли одного
продавца в разных городах склеиваются; не попавшие в топ больше не предлагаются). Сообщение продавцу для этих
объявлений предлагает отправку через «Sicher bezahlen».

## Обход Mecklenburg-Vorpommern

`src/mv.js`. Поиск по всей земле (`mecklenburg-vorpommern`, код `l61`, ~1 130 объявлений, 46 страниц). Раз в
3 часа идёт по страницам «новые», пока не встретит страницу без новых (`mv_seen`). В тихую сводку попадают новые
iPhone 13+, которых **ещё не видел мониторинг городов** (`seen`), с 💰 скидкой к рынку; такие объявления
помечаются в `seen` (`sent = 2`), чтобы города не прислали их повторно. Состояние — `settings.mv`
(`active`, `page`, `lastStart`, `collected`, `muted`, `lastSummary`). В `/cities` есть кнопка MV с карточкой
и выключателем.

## Telegram: команды и кнопки

| Команда | Что делает |
|---|---|
| `/deals` | лучшие по Германии за 24 ч |
| `/cities` | кнопки городов и MV → карточка: последние объявления, проверки, 🔕/🔔, ссылки поиска и DB |
| `/sell 15 Pro 256 32000` | цена продажи в ₴; `/sell` — таблица и курс; `… off` — удалить |
| `/margin 100` | порог маржи для 🔥 |
| `/price 600`, `/price 100-600`, `/price min 80`, `/price 15 Pro 550`, `/price off` | фильтр цены |
| `/stats` | статистика за сегодня по городам |
| `/help` | подсказка |

Кнопки под объявлением: «✍️ Написать продавцу» (`lt:<id>`), «🔗 Открыть», «🚆 Дорога» (bahn.de от Rostock Hbf).

Служебные HTTP-адреса Worker (`https://iphone-alert-bot.<subdomain>.workers.dev`):

| Адрес | Назначение |
|---|---|
| `POST /telegram` | webhook; проверка `X-Telegram-Bot-Api-Secret-Token == WEBHOOK_SECRET` |
| `GET /setup?key=RUN_KEY` | зарегистрировать webhook (`message`, `callback_query`) и меню команд |
| `GET /run?key=RUN_KEY&city=<slug>` | ручная проверка города; `&debug=1` — только показать разбор, без записи |
| `GET /run?key=RUN_KEY&city=germany` / `mv` / `digest` / `report` | лента Германии / шаг MV / сводка сейчас / отчёт сейчас |

## База данных (D1)

База `iphone-alert-bot` (id в `wrangler.toml`), привязка `DB`. Полная схема — `db/schema.sql`.

| Таблица | Что | Хранение |
|---|---|---|
| `seen` | виденные мониторингом городов объявления (`sent`: 0 — нет, 1 — прислано, 2 — ушло в сводку MV) | 30 дней |
| `city_state` | здоровье города, `initialized`, `muted` | — |
| `stats` | по дням и городам: проверки, ошибки, прислано (`city='mv'` — сводки MV) | — |
| `items` | присланные объявления (для карточек и «✍️»), `city='de'` — из ленты Германии | 30 дней |
| `settings` | `price`, `sell`, `margin`, `rate`, `mv` (JSON) | — |
| `prices` | цены всех увиденных iPhone 13+ — для медианы | 30 дней |
| `deal_seen` | что лента Германии уже оценила | 3 дня |
| `deals` | выгодные предложения: скидка, маржа, `score`, `kind`, `sent_at` (NULL — ждёт, 0 — пропущено) | 7 дней |
| `mv_seen` | что обход MV уже видел | 30 дней |

Первая проверка нового города — «молчаливая»: текущие объявления запоминаются, присылаются только новые.

```bash
npx --yes wrangler@4 d1 execute iphone-alert-bot --remote --command "SELECT city, checks, sent FROM stats WHERE day = date('now')"
```

## Запуск, проверка, публикация

Нужно: Node.js ≥ 20, аккаунт Cloudflare (`npx wrangler login`).

```bash
npm run check               # все города локально (разбор + отбор), без Telegram и D1
node scripts/check.js berlin
npm run deploy
npm run tail                # логи и cpuTime каждого запуска
```

Новая база с нуля: `npx wrangler d1 create iphone-alert-bot` → id в `wrangler.toml` → `npm run db:schema`
→ (по желанию) `node scripts/seed_prices.js > /tmp/p.sql && npx wrangler d1 execute iphone-alert-bot --remote --file /tmp/p.sql`.

## Эксплуатация и неполадки

| Симптом | Что делать |
|---|---|
| ⚠️ «<город>: сбой проверки» | разовые 403 Kleinanzeigen бывают; если часто — `npm run tail`; если сменилась разметка — `parseArticle` в `src/kleinanzeigen.js` |
| слишком много сообщений | `/price min …`, `/sell` + `/margin` (тогда звук только у 🔥), выключить город в `/cities` |
| нет сводки «Топ-5» | не было выгодных; проверить `SELECT kind, sent_at FROM deals ORDER BY found_at DESC LIMIT 10` |
| маржа не показывается | для модели/памяти нет записи `/sell` или нет курса (`settings.rate`) |
| `cpuTime` > 10 мс | ~7–15 мс — норма для страницы ~1 МБ; бесплатный тариф пока не обрывает; при обрывах — реже проверять крупные места или тариф Workers Paid (5 $/мес) |

## Ограничения и принятые решения

- **Лимиты Cloudflare (на аккаунт):** 10 мс CPU на запуск; **5 cron — заняты все** (2 здесь + 3 у
  `rostock-wohnung-bot`); D1: 100 тыс. записей и 5 млн прочитанных строк в сутки. KV не используем — его
  лимит записей занят квартирным ботом.
- **Сравнение с OLX.ua автоматически — нет:** OLX отвечает 403 (защита от ботов). Цены продажи задаёт владелец (`/sell`).
- **Не обходить защиту сайтов** (капчи, WAF, headless-браузеры, прокси). **Не писать продавцам автоматически** — бот готовит текст.
- Только частные продавцы и только предложения — выбор владельца. Дефекты и аксессуары в городах не отсеиваются (только пометки), в «лучших» — исключаются.
- Berlin и Hamburg проверяются раз в 10 минут, как остальные ⭐: два слота отданы ленте по Германии.
- Города и приоритеты — из таблицы владельца «iPhone_Города_из_Ростока.xlsx» (17.10.2026), перенесены в `src/cities.js`.
